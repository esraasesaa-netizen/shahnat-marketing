# مكتب تسويق شحنات — خطوات النقل إلى marketing.shahnat.net

هذا المجلد هو نفس المكتب اللي بنيتيه على Claude، بعد ما صار يشتغل لحاله:
- **الدخول** باسم مستخدم وكلمة مرور: إنتِ (مديرة المكتب) والمدير التنفيذي.
- **البيانات** (المهام، التوجيهات، الاجتماعات، ملف الشركة، المرفقات) محفوظة على Supabase ومشتركة للكل.
- **الموظفين الأذكياء** بيشتغلوا من سيرفر صغير على Vercel بمفتاح Anthropic API، والمفتاح ما بيظهر لأي حدا.
- **المدير التنفيذي**: بيشوف كل شي مباشرة، بدون أزرار تعديل.

> قبل ما تبلشي: انسخي نص **ملف الشركة** و**التوجيهات الدائمة** من المكتب القديم على Claude، لأن بياناته ما بتنتقل لحالها.

---

## الخطوة ١: Supabase (قاعدة البيانات وتسجيل الدخول) — مجاني

1. ادخلي على **supabase.com** واعملي حساب، وبعدين **New project**. سمّيه `shahnat-marketing`، واختاري كلمة سر قوية واحفظيها، واختاري أقرب منطقة.
2. من القائمة الجانبية: **SQL Editor** ← New query. افتحي ملف `supabase_setup.sql` من هذا المجلد، انسخي كل محتواه والصقيه، واضغطي **Run**.
3. **Authentication ← Users ← Add user ← Create new user**. اعملي حسابين، وفعّلي خيار **Auto Confirm User** لكل واحد:
   - `esraa@shahnat.team` مع كلمة المرور اللي بدك إياها (هذا حسابك)
   - `ceo@shahnat.team` مع كلمة مرور للمدير التنفيذي
4. ارجعي على **SQL Editor**، والصقي محتوى ملف `add_users.sql`، واضغطي **Run**. لازم يطلع جدول فيه الحسابين وأدوارهم.
5. **Authentication ← Sign In / Providers ← Email**: سكّري خيار **Allow new users to sign up**، عشان ما حدا يعمل حساب لحاله.
6. **Project Settings ← API** (أو Data API / API Keys): انسخي وخلّيهم عندك:
   - **Project URL**، وشكله `https://xxxx.supabase.co`
   - **anon public key** (أو **publishable key**)

> اسم المستخدم بالدخول هو الجزء قبل `@`. يعني إنتِ بتدخلي بـ `esraa`، والمدير بـ `ceo`.

## الخطوة ٢: مفتاح Anthropic API (لتشغيل الموظفين) — مدفوع حسب الاستخدام

1. ادخلي على **console.anthropic.com** واعملي حساب للشركة.
2. من **Billing** أضيفي رصيد، وحطي **حد أعلى للصرف الشهري** من إعدادات Limits.
3. **API Keys ← Create Key**، وانسخي المفتاح فوراً لأنه ما بيظهر مرة ثانية. **لا تحطيه بأي ملف، ولا تبعتيه لأي حدا.**

## الخطوة ٣: GitHub (مكان الكود) — مجاني

1. **github.com** ← اعملي حساب ← **New repository**، وسمّيه `shahnat-marketing-office` واختاري **Private**.
2. **Add file ← Upload files**، واسحبي **كل محتوى هذا المجلد** بما فيه مجلد `api`، واضغطي **Commit changes**.

## الخطوة ٤: Vercel (الاستضافة) — مجاني

1. **vercel.com** ← سجّلي دخول بحساب GitHub.
2. **Add New… ← Project** ← اختاري المستودع `shahnat-marketing-office` ← **Import**.
3. **Framework Preset**: خليه **Other**.
4. افتحي **Environment Variables**، وأضيفي هالثلاثة:

| الاسم | القيمة |
|---|---|
| `SUPABASE_URL` | Project URL من الخطوة ١ |
| `SUPABASE_ANON_KEY` | anon أو publishable key من الخطوة ١ |
| `ANTHROPIC_API_KEY` | المفتاح من الخطوة ٢ |

5. اضغطي **Deploy**. بعد دقيقة بيعطيكِ رابط تجريبي مثل `shahnat-marketing-office.vercel.app`.
6. افتحي الرابط، وادخلي بـ `esraa` وكلمة المرور، وجربي مهمة. وبعدين جربي الدخول بـ `ceo`.

## الخطوة ٥: الدومين الفرعي marketing.shahnat.net

1. بـ Vercel: المشروع ← **Settings ← Domains ← Add**، واكتبي `marketing.shahnat.net`.
2. Vercel بيعرضلك سجل **CNAME** وقيمته. **هاي القيمة هي "الهدف"**. انسخيها مثل ما هي بالضبط.
3. بهوستنجر ← دومينات ← shahnat.net ← DNS، أضيفي سجل:
   - النوع: **CNAME**
   - الاسم: `marketing`
   - الهدف: القيمة اللي أعطاكِ إياها Vercel
4. إذا ما عندك صلاحية تعديل الـ DNS، ابعتي القيم الثلاثة لصاحب حساب هوستنجر وهو بيضيفها.
5. بعد ساعة لـ 24 ساعة، Vercel بيكتب **Valid Configuration** وبيفعّل الـ HTTPS لحاله. وبيصير المكتب على **https://marketing.shahnat.net**.

## ملاحظات

- **تغيير النموذج** (اختياري): أضيفي متغير `ANTHROPIC_MODEL` بـ Vercel. الافتراضي `claude-sonnet-5-5`.
- **إضافة موظف بشري للفريق** لاحقاً: نفس الخطوة ١-٣ و١-٤ بدور `marketer`. هذا الدور حالياً **للاطلاع فقط**، وصلاحيات المسوقين بنضيفها بالمرحلة الجاية.
- **المرفقات**: أي ملف بترفعيه بياخذ رابط عشوائي طويل. أي حدا معه الرابط بيقدر يفتحه، فلا ترفعي ملفات سرية جداً.
- **المراحل الجاية**: ربط Google Search Console للسيو، وفحص الظهور بإجابات الذكاء الاصطناعي (GEO)، وتحليلات إنستغرام، وبيانات منصة شحنات، والتقارير والتنبيهات التلقائية.
